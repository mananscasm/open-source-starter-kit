# Maintainer Checklist

## Repository Setup

- Add README with purpose, install, usage, examples, and roadmap.
- Add LICENSE.
- Add CONTRIBUTING.md and CODE_OF_CONDUCT.md.
- Add issue templates and PR template.
- Add labels: `good first issue`, `help wanted`, `bug`, `docs`, `enhancement`.

## Pull Request Hygiene

- Keep PRs focused.
- Require screenshots for visual changes.
- Ask for tests or examples when behavior changes.
- Thank contributors specifically.

## Growth

- Publish small releases.
- Keep beginner issues well-scoped.
- Share useful changelogs instead of generic promotion.
