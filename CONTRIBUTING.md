# Contributing to open-source-starter-kit

Thanks for helping improve this project.

## Good Contributions

- Fix inaccurate content.
- Add examples, tests, screenshots, or explanations.
- Improve accessibility, formatting, or broken links.
- Add beginner-friendly issues with clear acceptance criteria.

## Pull Request Checklist

- Keep the change focused.
- Explain why the change is useful.
- Link the issue when possible.
- Add screenshots for UI/docs visual changes.

## Co-Authored Commits

For pairing, add this trailer to the commit message:

```text
Co-authored-by: Name <email@example.com>
```
